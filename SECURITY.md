# Security

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/agsoto/PowerMouse/security/advisories/new), rather than a public issue.

Include reproduction steps, affected version, Windows version, and whether PowerMouse or the target app was elevated. Remove private information from attached logs and screenshots.

Reports about input hooks, input injection, startup tasks, settings handling, UI Automation, and capture are welcome. The default branch is the supported development line.

Windows restricting input into a higher-privilege process is expected behavior.
